# L'Affiné — Maison de Fromage, depuis 1887

## 구조
- index.html (메인 + Grand Opening 로딩) / products.html / about.html / shop.html / journal.html / news.html / contact.html
- css/style.css — 공통 스타일 (토큰 · 컴포넌트 · 페이지별 섹션 · 반응형)
- css/loader.css, js/loader.js — 메인 로딩 화면 (세션당 1회, 클릭·Enter·Esc로 건너뛰기)
- js/main.js — 스크롤 등장, 진행 바, 맨 위로, 모바일 메뉴, 숙성 필터, 도감 필터·정렬·보기 전환, 뉴스 검색, 시음 달력, 폼 검증, FAQ
- img/ — 시안 SVG에서 추출한 이미지·로고·지도·문장(벡터)
- fonts/ — Tritopani 폰트 파일(Tritopani.woff2 등)을 여기에 넣으면 로딩 화면 손글씨에 적용됩니다.

## 반응형 기준
